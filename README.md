# GC-Content-Capstone-Project
GC Content Analysis of 3 Bacterial Genomes using Python, Biopython and Matplotlib. Data from NCBI. 
# GC Content Capstone Project

## Description
This project analyzes GC content variation in 3 bacterial genomes: Bacillus, E.coli, and Pseudomonas.

## Methods
- Data: NCBI Genome Database
- Tools: Python, Biopython, Pandas, Matplotlib
- Calculated GC% and visualized with bar chart, pie chart, and table

## Results
- Bacillus: 66.56%
- E.coli: 50.79% 
- Pseudomonas: 66.56%
